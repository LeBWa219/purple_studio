# Фиолетовая студия — сайт салона (брови / ногти, Саратов)

Одностраничный сайт на **React + Vite** с онлайн-виджетом записи (мультишаг: услуга → мастер → дата → время → контакты) и анимациями на **Motion** (ex-Framer Motion).

## Запуск

```bash
npm install
npm run dev        # дев-сервер → http://localhost:5173
npm run build      # прод-сборка в dist/
npm run preview    # посмотреть прод-сборку локально
```

## Что внутри

- `src/data.js` — **все данные студии в одном файле**: адрес, телефон, соцсети,
  услуги/цены, отзывы, лента «сегодня в студии», фото галереи, ссылка на Dikidi.
- `src/components/Booking.jsx` — виджет записи (шаги, слоты времени, валидация,
  экран успеха; принимает `preset` — предвыбранную услугу из меню/сцены).
- `src/components/Hero.jsx` + `LiveFeed.jsx` — кинетическая типографика
  (посимвольное появление, контурные слова-параллакс) и живая лента записей.
- `src/components/Showcase.jsx` — sticky-сцена услуг: экран «залипает», слайды
  сменяются по скроллу (на мобильных — карточки-фолбэк).
- `src/components/GalleryH.jsx` — горизонтальная лента работ: вертикальный скролл
  превращается в движение фотографий по горизонтали (на мобильных — сетка).
- `src/components/Bento.jsx` — bento-блоки с count-up рейтингом.
- `src/components/PriceMenu.jsx` — прайс «как в кофейне» с точечными лидерами;
  клик по строке открывает запись с выбранной услугой.
- `src/components/ChatReviews.jsx` — отзывы в виде переписки.
- `src/styles.css` — дизайн-система + «awwwards-слой» в конце файла.

## Перед показом клиенту — заменить заглушки в `src/data.js`

1. ⚠️ **Цены и длительности услуг** — сейчас правдоподобные, сверить с реальным прайсом.
2. ⚠️ **Имена мастеров** (Алина, Дарья) — плейсхолдеры.
3. **`dikidi`** — заменить `"#booking"` на публичную страницу записи студии в Dikidi
   (вида `https://dikidi.net/…`). Пока финальная кнопка в виджете ведёт в никуда.
4. **`telegram`** — уточнить актуальный ник Telegram (в 2ГИС указан просто «TG»).
5. **Отзывы** — заменить на реальные из 2ГИС/VK (сейчас демо-тексты).
6. **Расписание** (`hours: "ежедневно 9:00 – 20:00"`) — сверить.

## Как подключить живую запись Dikidi

Сейчас слоты времени — демо (детерминированная «занятость» в `Booking.jsx`, функция `slotBusy`).
Варианты подключения:

- **Простой (рекомендую на старте):** кнопка «Записаться онлайн» ведёт на страницу Dikidi
  студии — реальные свободные окна показывает сам Dikidi.
- **Продвинутый:** у Dikidi есть API — при наличии согласия студии можно подтягивать
  свободные окна в виджет (заменить `slotBusy` на реальный запрос).

## Дизайн

- **Светлая «девчачья» тема**: кремовый фон, пастельно-лиловые градиенты, элегантный
  serif (Playfair Display) в заголовках + Manrope в тексте, кириллица, Google Fonts.
- **Галерея работ** (`#gallery`) — 4 демо-фото из Wikimedia Commons (CC BY-SA),
  в футере есть строка с кредитами. Перед показом заменить на реальные фото студии
  (файлы в `public/img/`, список — `GALLERY` в `src/data.js`).
- **Фон**: белый лист с фиолетовыми цветами у правого края (`public/img/bg-petals.png`,
  фото предоставлено заказчиком) + **живой canvas-слой падающих лепестков**
  (`PetalCanvas.jsx`): лепестки медленно кружатся всегда, при скролле ускоряются
  (чем быстрее листаешь — тем сильнее «лепестковый дождь»). Уважает
  `prefers-reduced-motion` (лепестки просто рассыпаны статично).
- Анимации: stagger-hero, scroll-reveal, «магнитные» кнопки, marquee, подсветка
  курсора на карточках услуг, переходы шагов виджета. Уважает `prefers-reduced-motion`.
